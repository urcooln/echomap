Teacher Communication Helper
Create a prominent feature on the Teacher Dashboard called:
"What Does This Mean?"
The purpose is to help teachers quickly understand student communication and know how to respond in the classroom.
This feature should be designed for busy educators and use simple, actionable language rather than clinical terminology.
Search Experience
Provide a search bar at the top of the Teacher Dashboard.
Placeholder text:
Enter a phrase you've heard the student say...
Examples:
"Let's save the city!"
"Come on!"
"We have a cat in our bed!"
"Blast off!"

When a phrase is entered, search the student's Communication Dictionary, Gestalt Library, Session History, Team Notes, and approved clinician insights.

Design Requirements
The Teacher Dashboard should feel like:
A communication support tool
A classroom resource
A quick-reference guide
It should NOT feel like:
A clinical documentation system
An assessment platform
A therapy report
Minimize jargon and maximize practical classroom guidance.
