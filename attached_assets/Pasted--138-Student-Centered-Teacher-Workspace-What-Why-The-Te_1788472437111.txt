#138 - Student-Centered Teacher Workspace
What & Why
The Teacher experience should be organized around students, not tools.
Currently, Phrase Dictionary and Shared Moments exist as standalone navigation destinations. This creates an unnecessary workflow where teachers must navigate to a tool first and then find a student.

Instead, teachers should begin in Classroom Overview, select a student, and access all student-specific communication supports within that student's profile.

This creates a more intuitive workflow and mirrors how teachers naturally think about classroom support.

Done looks like
Classroom Overview remains the teacher landing page.
My Students remains the primary student-management view.
Phrase Dictionary is removed from the left navigation.
Shared Moments is removed from the left navigation.
Selecting a student opens a Student Workspace/Profile.
The Student Workspace contains dedicated sections for:
Student Overview
Phrase Dictionary
Shared Moments
Team Notes
AAC Information (if available)
Communication Profile
Classroom Supports
All Phrase Dictionary searches are scoped to the selected student.
All Shared Moments are scoped to the selected student.
Teachers never need to leave the student profile to access student-specific communication information.
The interface clearly indicates which student is currently selected.
Navigation becomes:
Classroom Overview
Resources
Inbox
My Students
Settings
Student Profile Layout

Classroom → Student → Communication Supports

instead of:

Tool → Student → Information

That matches how teachers naturally work and reduces navigation friction.
