Add AAC Planning Workflow

Why

ChildLed currently helps clinicians identify and track meaningful child language, but there is no workflow connecting communication insights to AAC vocabulary planning.

Clinicians frequently identify phrases that should be considered for inclusion on a child’s AAC system. These decisions are often tracked outside the platform.

ChildLed should support this process by allowing clinicians to flag dictionary phrases for AAC consideration and manage them through a simple planning workflow.

⸻

New Feature: AAC Planning

Add a new optional child-scoped section called:

AAC Planning

or

AAC Vocabulary Candidates

This feature does not directly program AAC devices.

Its purpose is to help clinicians organize phrases that may need to be added during AAC programming sessions.

⸻

Workflow

From the Communication Dictionary:

Each phrase should support:

* Add to AAC Planning
* Remove from AAC Planning

When selected:

The phrase is added to the child’s AAC Planning list.

⸻

AAC Planning View

Display:

High Priority

Frequently used phrases that have been marked for AAC consideration.

For each phrase show:

* Phrase text
* Occurrence count
* First observed date
* Most recent observation date
* Communication function
* Settings observed (home, school, therapy)

Actions:

* Mark Added to Device
* Review Later
* Remove from AAC Planning

⸻

Optional Future Suggestions

ChildLed may suggest AAC candidates based on:

* High frequency
* Cross-setting use
* Functional communication value
* Emerging language trends

Suggested phrases should never be automatically added.

Clinicians remain responsible for AAC decisions.

⸻

Clinical Principles

* AAC Planning is a workflow tool, not device programming.
* Dictionary phrases remain the source of truth.
* AAC Planning does not alter language-stage analysis, occurrence counts, or clinical evidence.
* Not every child requires AAC support.
* The feature should remain optional and child-specific.

⸻

Success Criteria

A clinician can:

1. Review a phrase in the Communication Dictionary.
2. Select Add to AAC Planning.
3. View all AAC candidates in one place.
4. Track whether a phrase has been reviewed, added, or deferred.
5. Use ChildLed as a bridge between communication observations and AAC implementation.
